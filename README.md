# micro-ccl

Minimal MPI-style collective communication library built directly on
`libibverbs` (RDMA verbs), plus a benchmark harness comparing it against
OpenMPI.

Status: stage 1 (skeleton) in progress. See `docs/setup.md` to bring up a
Soft-RoCE dev environment. Full README -- architecture, diagrams, benchmark
results, limitations -- lands at the end of the project (stage 8).
